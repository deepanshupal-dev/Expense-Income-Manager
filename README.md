# 💰 Expense & Income Manager

A React-based expense and income management application that helps users manage their financial transactions in a simple and organized way.

## ✨ Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Search transactions by title
- Filter transactions by Income or Expense
- Calculate total income
- Calculate total expenses
- Calculate total balance
- Form validation
- Store transactions using LocalStorage
- Data persists after page refresh
- Responsive glassmorphism UI

## 🛠️ Technologies Used

- React
- JavaScript
- HTML
- CSS
- LocalStorage

## 🔄 CRUD Operations

| Operation | Functionality |
|---|---|
| Create | Add a new transaction |
| Read | Display transactions |
| Update | Edit an existing transaction |
| Delete | Delete a transaction |

## 📋 Transaction Details

Each transaction contains:

- Title
- Amount
- Type
- Category

### Transaction Types

- Income
- Expense

### Categories

- Food
- Job
- Shopping
- Travel
- Bills
- Other

## 🔍 Search & Filter

- Search transactions by title
- Filter by Income
- Filter by Expense
- View all transactions
- Combined search and filter functionality

## 💾 Data Persistence

Transaction data is stored in the browser's LocalStorage.

This allows transactions to remain available after refreshing the page.

## ✅ Form Validation

- Title cannot be empty
- Amount must be greater than zero
- Invalid transaction data is rejected
